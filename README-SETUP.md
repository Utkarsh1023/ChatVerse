# Setup (scaffold)

## Backend
1. Open terminal in: `premium-chat/backend`
2. Install deps: `npm install` (done)
3. Create `.env` from `.env.example`
4. Run dev: `npm run dev`


Health check:
- GET http://localhost:4000/health

## Frontend
1. Open terminal in: `premium-chat/frontend`
2. Install deps: `npm install`
3. Run dev: `npm run dev`

Open:
- http://localhost:5173
